# Changelog

## 1.0.0 - 2026-08-17

- first runnable NEXUS.sf open core;
- dependency-free Dart CLI and HTTP service;
- exact routing and external-node registration;
- one-use authorization gate for `execute.*` capabilities;
- payload-free JSONL traces;
- local UVO, UGAI, EVE and ECO adapters;
- analyzer, contract, HTTP smoke and compiled-executable gates;
- Apache-2.0 licensing and documented edition boundary.
